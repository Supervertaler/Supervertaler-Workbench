Supervertaler Workbench

A free, open-source standalone CAT tool.

This project is no longer actively developed.

Workbench still works, the source is still open, and the last release stays downloadable. But it is not receiving new features, and bug reports are unlikely to be acted on.

A standalone CAT tool has to do one thing above all else: import a file, let you translate it, and export it back out with the formatting exactly as it came in – for every format a client might send. Getting that right across the full range of real-world files is a bigger job than one person can do properly alongside everything else.

Supervertaler for Trados takes the other route: it lets Trados Studio handle the file processing, which Trados is very good at, and puts the AI translation, terminology and search tools on top of it. That is where the work goes now.

If you use Workbench and it does what you need, carry on – nothing is being taken away. The documentation stays online, and the code is yours to fork.
